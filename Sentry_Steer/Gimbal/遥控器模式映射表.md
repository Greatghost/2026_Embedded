# 哨兵遥控器模式映射表

> 机型：`ROBOT = TIGER`
> 协议：WBUS（Futaba S.BUS 兼容），100kbps，USART3 DMA 双缓冲
> 更新日期：2026-07-13

---

## 一、物理拨杆 → 代码变量映射

遥控器（乐迪 AT9S Pro / DJI DT7）物理开关通过 WBUS 协议的 16 个通道传输，经由 `WBUS_UpdateRemoteController()` 解码为代码中的 `RemoteController` 结构体。

### 1.1 物理开关 → WBUS 通道

| 遥控器标签 | 开关类型 | WBUS 通道 | 说明 |
|-----------|---------|-----------|------|
| **SA** | 双位拨杆（上/下） | CH5 | 用于合成 LEFT_SW |
| **SC** | 三位拨杆（上/中/下） | CH7 | 直接映射为 RIGHT_SW |
| **SD** | 双位拨杆（上/下） | CH8 | 用于合成 LEFT_SW |

> **注意**：原三位拨杆 CH6 已损坏，现用 CH5 + CH8 两个双位拨杆合成 LEFT_SW。详见 `wbus_decoder.c:170-186`。

### 1.2 WBUS 通道 → 代码变量

| WBUS 通道 | 代码变量 | 说明 |
|-----------|---------|------|
| CH1 | `rc.ch[LEFT_CH_LR]` | 左摇杆左右 |
| CH2 | `rc.ch[LEFT_CH_UD]` | 左摇杆上下 |
| CH3 | `rc.ch[RIGHT_CH_UD]` | 右摇杆上下 |
| CH4 | `rc.ch[RIGHT_CH_LR]` | 右摇杆左右 |
| CH5 + CH8 | `rc.s[LEFT_SW]` | 左拨杆（合成，见下表） |
| CH7 | `rc.s[RIGHT_SW]` | 右拨杆 |

### 1.3 LEFT_SW 合成逻辑

```
CH5 = Down        →  LEFT_SW = Down    (下电)
CH5 = Up, CH8 = Up   →  LEFT_SW = Up      (遥控手动模式)
CH5 = Up, CH8 = Down  →  LEFT_SW = Mid     (NUC/PC 模式)
```

| SA (CH5) | SD (CH8) | → | LEFT_SW |
|--------|---------|---|---------|
| 下 | 下 | → | **Down** |
| 上 | 上 | → | **Up** |
| 上 | 下 | → | **Mid** |

> SA=下、SD=上（即 CH5=Down, CH8=Up）与 SA=下、SD=下 效果相同，因为 CH5=Down 时忽略 CH8，统一为 LEFT_SW=Down。

## 二、完整档位矩阵

### 2.1 总览（物理拨杆视角）

```
                       右拨杆 SC (RIGHT_SW)
                     Up         Mid         Down
              ┌────────────┬────────────┬────────────┐
SA=上  Up     │  手动打弹   │ 锯齿波测试  │  手动移动   │
SD=上         │ UNSTOPPABLE │  (代码原有)  │  (不打弹)   │
              ├────────────┼────────────┼────────────┤
SA=上  Mid    │  辅瞄测试   │  比赛模式   │ NUC模式①   │
SD=下         │ (纯自瞄)    │            │  (可旋转)   │
              ├────────────┼────────────┼────────────┤
SA=下  Down   │ 检录射击    │ 检录小陀螺  │   下电      │
SD=下         │ + 小陀螺    │  (反方向)   │            │
              └────────────┴────────────┴────────────┘
```

> ① LEFT_SW=Mid, RIGHT_SW=Down 同时承载两种模式：若 `Previous_rc_Right_SW == Down` 进入**导航模式**（底盘不转），否则进入 **NUC 模式**（旋转可选，由上位机 RotateState 控制）。

### 2.2 逐档位详情

#### SA=上 / SD=上 / SC=下 —— 手动移动

| 项目 | 设置 |
|------|------|
| 代码路径 | `LEFT_SW=Up, RIGHT_SW=Down` ([ChassisSolver.c:693-718]) |
| 云台模式 | `GIMBAL_ACT_MODE`（摇杆手动控制） |
| 射击模式 | `SHOOT_POWERDOWN_MODE`（不打弹） |
| 底盘模式 | `NOT_FOLLOW_GIMBAL` |
| 底盘速度 | 右摇杆手动（x/y），不旋转 |
| 超级电容 | 接电池 |
| 云台 Yaw | 左摇杆左右 → `target_big_yaw_angle` |
| 云台 Pitch | 左摇杆上下 → `target_pitch_angle` |

#### SA=上 / SD=上 / SC=中 —— 锯齿波测试

| 项目 | 设置 |
|------|------|
| 代码路径 | `LEFT_SW=Up, RIGHT_SW=Mid` ([ChassisSolver.c:719-763]) |
| 云台模式 | `GIMBAL_ACT_MODE`（摇杆 + 锯齿波叠加） |
| 射击模式 | `SHOOT_POWERDOWN_MODE` |
| 底盘模式 | `SPEED_FOLLOW` |
| 底盘速度 | 右摇杆手动（x/y），不旋转 |
| 超级电容 | **超级电容** |
| 特殊 | Yaw 角叠加 6° 幅值 / 250ms 周期锯齿波 |

#### SA=上 / SD=上 / SC=上 —— 手动打弹

| 项目 | 设置 |
|------|------|
| 代码路径 | `LEFT_SW=Up, RIGHT_SW=Up` ([ChassisSolver.c:764-808]) |
| 云台模式 | `GIMBAL_ACT_MODE`（摇杆手动控制） |
| 射击模式 | `SHOOT_FIRE_MODE` 或 `SHOOT_UNSTOPPABLE_MODE`（见下方） |
| 底盘模式 | `FOLLOW_GIMBAL` |
| 底盘速度 | 静止 |
| 超级电容 | 接电池 |
| 特殊 | 右摇杆上推 >330 → `is_shoot=TRUE`（拨盘单发） |

**UNSTOPPABLE 子模式触发**：当**左摇杆任意轴**偏差 >330 **且** **右摇杆任意轴**偏差 >330 时，射击模式切换为 `SHOOT_UNSTOPPABLE_MODE`；否则保持 `SHOOT_FIRE_MODE`。

#### SA=上 / SD=下 / SC=上 —— 辅瞄测试（纯自瞄）

| 项目 | 设置 |
|------|------|
| 代码路径 | `LEFT_SW=Mid, RIGHT_SW=Up` ([ChassisSolver.c:651-681]) |
| 云台模式 | `GIMBAL_AUTO_AIM_MODE`（上位机控制） |
| 射击模式 | `SHOOT_AUTO_AIM_MODE` |
| 底盘模式 | `NOT_CONTROL_MODE` |
| 底盘速度 | 静止 |
| 超级电容 | 接电池 |
| 特殊 | 右摇杆上推 >330 → `is_shoot=TRUE`（自瞄下也可手动打弹） |

#### SA=上 / SD=下 / SC=中 —— 比赛模式

| 项目 | 设置 |
|------|------|
| 代码路径 | `LEFT_SW=Mid, RIGHT_SW=Mid` → `PCStateControl()` ([ChassisSolver.c:35-114]) |
| 云台模式 | `GIMBAL_AUTO_AIM_MODE` |
| 射击模式 | `SHOOT_AUTO_AIM_MODE` |
| 底盘模式 | 由上位机 `RotateState` 决定（见 2.3 节） |
| 底盘速度 | x/y 来自 `NAV_cmd`，旋转来自上位机 |
| 超级电容 | 由上位机 `CapState` 决定 |
| 保护 | Pitch > 80° 或 Roll > 60° → `setAllModeOff()`（翻车保护） |

#### SA=上 / SD=下 / SC=下 —— NUC 模式 / 导航模式

| 项目 | NUC 模式 | 导航模式 |
|------|---------|---------|
| 代码路径 | `LEFT_SW=Mid, RIGHT_SW=Down` ([ChassisSolver.c:645-647]) | 同上，但触发条件不同 ([ChassisSolver.c:627-640]) |
| 触发条件 | RIGHT_SW 非从 Down 切换过来 | RIGHT_SW 从 Down 切换过来（`Previous_rc_Right_SW == Down`） |
| 云台模式 | `GIMBAL_AUTO_AIM_MODE` | `GIMBAL_ACT_MODE` |
| 射击模式 | `SHOOT_AUTO_AIM_MODE` | `SHOOT_POWERDOWN_MODE` |
| 底盘模式 | 由上位机 `RotateState` 决定 | `NOT_FOLLOW_GIMBAL` |
| 底盘旋转 | 可选（RotateState 1/2/3 档） | **不旋转**（`speed_w = 0`） |

### 2.3 PCStateControl 旋转速度分档

当 `LEFT_SW=Mid, RIGHT_SW=Mid/Down` 进入 `PCStateControl()` 时，上位机 `FireCode` bit[7:6] 控制旋转速度：

| RotateState | `chassis_speed_w` | 值 (TIGER, MAX=16.0) |
|-------------|-------------------|----------------------|
| 0 | 0 | 不旋转 |
| 1 | `0.5 × MAX_YAW_SPEED` | 8.0 rad/s |
| 2 | `0.75 × MAX_YAW_SPEED` | 12.0 rad/s |
| 3 | `1.0 × MAX_YAW_SPEED` | 16.0 rad/s |

## 三、键鼠模式（KEY_MOUSE）

键鼠模式通过 WBUS 自动识别（鼠标/键盘设备），与遥控器拨杆的 `LEFT_SW=Mid` 或 `LEFT_SW=Up` 档位共存。**右拨杆（RIGHT_SW）非 Mid 时切回遥控器模式**。

摇杆/射击逻辑与遥控器不同，由 `DJIKeyMouseUpdate()` 独立处理：

| 操作 | 效果 |
|------|------|
| 鼠标移动 X/Y | Yaw/Pitch 目标角（系数 0.005°） |
| 鼠标滚轮 Z | Pitch 微调 |
| 左键按住 | `is_shoot = TRUE`（连发） |
| 左键单击 | `single_shoot_flag = TRUE`（单发） |
| 右键按住 | 进入 `GIMBAL_AUTO_AIM_MODE` |
| 右键松开 | 退回到 `GIMBAL_ACT_MODE` |
| R + Z | 小符模式 |
| R + X | 大符模式 |
| E 松开 | Yaw 角度 +180° |
| Shift 按住 | 超级电容 |
| Ctrl 按住 | 小陀螺 `speed_w = ±1.0`（按两次反转方向） |
| V / C 按住 | 过洞模式（底盘跟随 + 限功率） |
| Q 单击 | 切换底盘形态（X 型 ↔ 十字型） |
| W/A/S/D | 底盘速度控制 |

## 四、代码枚举速查

### GIMBAL_ACTION（7 种）
| 枚举值 | 含义 |
|--------|------|
| `GIMBAL_POWERDOWN` | 掉电 |
| `GIMBAL_ACT_MODE` | 手动控制 |
| `GIMBAL_AUTO_AIM_MODE` | 自瞄 |
| `GIMBAL_TEST_MODE` | 测试 |
| `GIMBAL_SI_MODE` | 系统辨识 |
| `GIMBAL_SMALL_BUFF_MODE` | 小符 |
| `GIMBAL_BIG_BUFF_MODE` | 大符 |

### SHOOT_ACTION（7 种）
| 枚举值 | 含义 |
|--------|------|
| `SHOOT_POWERDOWN_MODE` | 掉电 |
| `SHOOT_CHECK_MODE` | 自检 |
| `SHOOT_TEST_MODE` | 弹道测试 |
| `SHOOT_FIRE_MODE` | 射击 |
| `SHOOT_AUTO_AIM_MODE` | 自瞄 |
| `SHOOT_SUPPLY_MODE` | 补给 |

| 枚举值 | 含义 |
|--------|------|
| `NOT_CONTROL_MODE` | 无控制 |
| `NOT_FOLLOW_GIMBAL` | 仅底盘运动 |

| `SPEED_FOLLOW` | 速度矢量跟随 |
| `NAVIGATION_MODE` | 导航模式 |
