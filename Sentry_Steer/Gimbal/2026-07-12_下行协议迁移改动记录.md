# 2026-07-12 下行协议迁移改动记录

> 基于 2026-07-11 上位机下发协议，将下行帧从旧 2 种扩展为新 5 种（0x00~0x04）。
> 与上位机 **不兼容**，必须同步切换。

## 修改文件

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `application/inc/pc_serial.h` | 重构 | 删旧下行结构体，新增 5 种新帧 + DownlinkTypeID 宏；PCbuffer 扩容至 107B |
| `application/src/pc_serial.c` | 重构 | PCReceive 改为 switch(DownlinkTypeID) 分发；注释 pc_recv_data_1 |
| `Task/src/GimbalTask.c` | 清理 | 注释 2 处 pc_recv_data_temp 死代码 |
| `bsp/boards/inc/bsp_can.h` | 新增 | Can1SendMapPath / Can1SendCustomInfo 声明 |
| `bsp/boards/src/bsp_can.c` | 新增 | 两个 stub 函数体（TODO 多帧 CAN 分段传输） |

## 下行帧变更明细

### 旧协议 → 新协议

| DownlinkTypeID | 旧 | 新 | 变化 |
|---------------|-----|-----|------|
| 0x00 | PCRecvData_1 (18B, 含 SentryCmd) | GimbalControlFrame (13B) | 去掉 SentryCmd 和 tail |
| 0x01 | SentryCoord_t (18B, 坐标) | SentryCommandFrame (6B, 纯 SentryCmd) | 语义完全改变 |
| 0x02 | — | MapPathFrame (107B, 0x0307 转发) | 新增 |
| 0x03 | — | CustomInfoFrame (36B, 0x0308 转发) | 新增 |
| 0x04 | — (原 0x01) | SentryCoordinateFrame (17B, 坐标) | 从 0x01 搬家 |

### 0x00 GimbalControlFrame (13B)

```
[0]='!' [1]=0x00 [2]=vel_x [3]=vel_y [4-7]=yaw [8-11]=pitch [12]=fire_code
```

### 0x01 SentryCommandFrame (6B)

```
[0]='!' [1]=0x01 [2-5]=sentry_cmd (uint32 LE)
```

SentryCmd 姿态位宽: bit21-22(1~3) → bit21-23(1~6)

### 0x04 SentryCoordinateFrame (17B)

```
[0]='!' [1]=0x04 [2-3]=x_cm [4-5]=y_cm [6-15]=reserved [16]=CRC8
```

与旧 0x01 内容一致，仅 type_id 从 0x01 变为 0x04。

### 0x02/0x03

接收路径已预留，CAN 转发为 stub（待实现多帧分段传输）。

## 不变项

- 上行 TypeID=0~9 帧结构完全不变
- FireCode 位域语义不变
- 全局变量 `pc_yaw`/`pc_pitch`/`NAV_cmd`/`Shoot_Cmd`/`PC_statecontrol`/`current_posture`/`sentry_position_x/y_cm` 不变
- Gimbal_Autoaim_Cal / Gimbal_Small_Buff_Cal 等消费者不受影响

## 编译注意事项

- Keil 需重新编译目标对象: pc_serial, bsp_can, gimbaltask
- PCbuffer 从 18B 扩到 107B，栈空间增大 ~89B
- 上位机 gimbal_driver 需同步切换到 DownlinkTypeID 分包模式
