# 开机启动音效移植指南

## 概述

本项目使用无源蜂鸣器通过PWM控制实现开机启动音效。蜂鸣器位于Gimbal板，通过TIM4通道3输出PWM信号驱动。

## 相关文件

| 文件 | 功能 | 必需性 |
|------|------|--------|
| bsp_buzzer.c | 蜂鸣器控制与音乐播放实现 | **必需** |
| bsp_buzzer.h | 蜂鸣器接口声明 | **必需** |
| bsp_led.c | LED控制函数实现 | 可选(音乐播放后LED切换) |
| bsp_led.h | LED接口声明 | 可选(音乐播放后LED切换) |

## 文件依赖关系

```
bsp_buzzer.h
  ├── main.h (HAL库)
```

## 移植到其他项目步骤

### 1. 硬件准备

- 无源蜂鸣器一个
- STM32开发板，至少有一个空闲定时器通道
- 蜂鸣器连接到定时器PWM输出引脚

### 2. PWM定时器配置

使用STM32CubeMX配置定时器：

1. 选择一个定时器（如TIM4）
2. 设置通道为PWM输出模式
3. 配置参数：
   - Prescaler (PSC): 根据时钟频率计算
   - Counter Mode: Up
   - Auto-Reload Register (ARR): 初始值设为最大
   - Pulse (CCR): 设为ARR的一半（50%占空比）

**时钟频率计算示例：**
```
假设系统时钟168MHz，定时器时钟84MHz
设置PSC = 0，则定时器时钟 = 84MHz
period = (84MHz / 目标频率) - 1
```

### 3. 修改代码适配

**步骤A：复制文件**

将本文件夹中的以下文件复制到目标项目：
- `bsp_buzzer.c` → 目标项目的源码目录
- `bsp_buzzer.h` → 目标项目的头文件目录

如需LED功能，也复制：
- `bsp_led.c` → 目标项目的源码目录
- `bsp_led.h` → 目标项目的头文件目录

**步骤B：修改定时器句柄**

在 `bsp_buzzer.c` 中修改定时器引用：

```c
// 原代码使用TIM4
extern TIM_HandleTypeDef htim4;  // 改为你的定时器句柄

void Set_Buzzer_Frequency(uint32_t frequency)
{
    uint32_t period = (8400000 / frequency) - 1;  // 修改8400000为你的定时器时钟频率(Hz)
    __HAL_TIM_SET_AUTORELOAD(&htim4, period);      // 改为你的句柄
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, period / 2);  // 改为你的通道
}
```

**步骤C：修改PWM启动/停止**

```c
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_3);   // 启动PWM - 改为你的句柄和通道
HAL_TIM_PWM_Stop(&htim4, TIM_CHANNEL_3);    // 停止PWM - 改为你的句柄和通道
```

**步骤D：修改LED引脚（如使用LED功能）**

在 `bsp_led.c` 中修改GPIO端口和引脚：

```c
void LED_On(uint16_t GPIO_Pin)
{
    HAL_GPIO_WritePin(GPIOH, GPIO_Pin, GPIO_PIN_SET);  // GPIOH改为你的LED端口
}

void LED_Off(uint16_t GPIO_Pin)
{
    HAL_GPIO_WritePin(GPIOH, GPIO_Pin, GPIO_PIN_RESET);  // GPIOH改为你的LED端口
}
```

在 `Initialization_Completed()` 函数末尾修改LED引脚号：

```c
LED_Off(GPIO_PIN_12);  // 改为你的LED引脚
LED_On(GPIO_PIN_11);   // 改为你的LED引脚
```

**步骤E：删除不需要的功能**

如果不需要LED功能，在 `bsp_buzzer.h` 中移除：
```c
// 删除这行
#include "bsp_led.h"
```

在 `bsp_buzzer.c` 的 `Initialization_Completed()` 函数末尾删除：
```c
// 删除这两行
LED_Off(GPIO_PIN_12);
LED_On(GPIO_PIN_11);
```

如果不需要aRGB LED功能，删除 `bsp_led.c` 中的 `aRGB_led_show()` 函数及其对外部 `htim5` 的引用。

### 4. 添加头文件路径

在项目编译设置中添加头文件包含路径：
- Keil: Options → C/C++ → Include Paths
- STM32CubeIDE: Project Properties → C/C++ Build → Settings → Include paths

### 5. 调用开机音乐

在 `main.c` 的初始化流程末尾调用：

```c
#include "bsp_buzzer.h"

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_TIM4_Init();  // 确保定时器已初始化
    
    // 其他初始化...
    
    Initialization_Completed();  // 播放开机音乐
    
    while (1)
    {
        // 主循环
    }
}
```

## 核心函数说明

### Set_Buzzer_Frequency(uint32_t frequency)

设置蜂鸣器播放频率，频率对应音高：

```c
void Set_Buzzer_Frequency(uint32_t frequency)
{
    uint32_t period = (8400000 / frequency) - 1;  // 计算ARR值
    __HAL_TIM_SET_AUTORELOAD(&htim4, period);      // 设置周期
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, period / 2); // 50%占空比
}
```

参数说明：
- `frequency = 0`：停止发声（静音）
- `frequency > 0`：播放对应频率的音符

**移植时需修改的参数：**
- `8400000` → 改为你的定时器时钟频率(Hz)
- `htim4` → 改为你的定时器句柄
- `TIM_CHANNEL_3` → 改为你的PWM通道

### Initialization_Completed(void)

开机时调用的音乐播放函数，根据宏定义播放选定的音乐，播放完成后自动停止PWM并切换LED状态。

### PC_On(void)

PC连接成功提示音，播放简短的双音提示。

## 添加新音乐步骤

### 1. 添加宏定义

在宏定义注释区添加新选项：

```c
// BUZZER_MUSIC_NEW_MUSIC - 新音乐名称描述
```

### 2. 编写音乐代码

在 `Initialization_Completed()` 函数的条件编译块中添加：

```c
#elif defined(BUZZER_MUSIC_NEW_MUSIC)
    // ========== 新音乐名称 (BPM) ==========

    // 音符播放格式：
    // Set_Buzzer_Frequency(频率); HAL_Delay(音符时长); Set_Buzzer_Frequency(0); HAL_Delay(停顿间隙);

    // 例如：播放E5四分音符
    Set_Buzzer_Frequency(659);  // E5
    HAL_Delay(333);             // 四分音符时长(180BPM)
    Set_Buzzer_Frequency(0);    // 停顿
    HAL_Delay(10);              // 短暂静音分隔

    // ==========================================================
```

### 3. 启用新音乐

修改顶部宏定义：

```c
#define BUZZER_MUSIC_NEW_MUSIC 1
```

## 无源蜂鸣器技术说明

- **工作原理**：通过PWM信号驱动，频率决定音高，占空比决定音量
- **限制**：只能播放单音符，无法同时播放和弦
- **频率范围**：通常有效范围 100Hz - 5000Hz
- **PWM配置**：本项目使用TIM4，时钟频率8.4MHz，通道3输出

## 使用注意事项

1. 音乐播放期间会阻塞程序执行（使用HAL_Delay）
2. 播放完成后会自动停止PWM输出
3. LED状态会在播放完成后切换（LED11亮，LED12灭）
4. 添加新音乐时建议先在小节间加入短暂静音分隔音符
5. 频率设置0可实现静音/停顿效果
